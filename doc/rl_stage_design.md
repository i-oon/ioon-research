## ปัญหาที่วัดพบ

1. **เส้นวัดการล้มต่ำเกินจริง** — expert ทั้ง 48 คลิปอยู่ที่ 0.534–0.564 m ตลอด แต่เกณฑ์ตั้งไว้ 0.30 · policy ไปนั่งที่ 0.374 ลำตัวขนานพื้น (upz 0.999) จึงไม่โดนปรับเรื่องเอียง และ reward ไม่มีเทอมความสูง
2. **policy มองไม่เห็นเป้าหมาย** — เป้าอยู่แค่ในสูตร reward ซึ่งมีเฉพาะตอนเทรน เทรนเสร็จเหลือ `obs → action` ที่ไม่มีตัวแปรเป้า ป้อนเป้าใหม่พฤติกรรมเหมือนเดิมทุกประการ → ทดสอบ claim ไม่ได้
3. **reward ที่ deploy ได้จริงยังไม่เคยถูกพิสูจน์** — รันทั้งหมดใช้โหมดวินิจฉัยที่อ่านความเร็วจริงจากฟิสิกส์ ส่วนโหมดจริงเดาจาก action อย่างเดียว ซึ่งวัดแล้วว่ามีน้ำหนักเชิงสาเหตุ < 3%
4. **ค่าเฉลี่ยทั้งคลิปไม่ตรงกับพฤติกรรมจริง** — คลิปเร่งจาก 0.050 → คงที่ 0.16–0.19 → ชะลอ 0.091 · ค่าเฉลี่ย 0.152 ไม่มีอยู่จริงในช่วงไหนของคลิป
5. **การประเมินวัดได้จุดเดียว** — 10 episodes ได้ตัวเลขเหมือนกันทุกหลัก สภาพเริ่มต้นไม่สุ่ม → n = 1

## ข้อโต้แย้งที่ยังตอบไม่ได้

ตัวควบคุมคือ velocity-tracking มาตรฐาน และต่างจากของทั่วไป **แค่หน่วย**

```
Fr = v / √(gL)   ⇒   v_B1 / v_แมลง = √(L_B1 / L_แมลง)
```

รู้ความยาวขาสองตัว = คูณสเกลาร์ตัวเดียวจบ ไม่ต้องมี world model และ dynamic similarity เป็นของ Alexander ยุค 70 **"พิกัดร่วมที่ข้ามร่างได้" จึงไม่ใช่ contribution**

เงื่อนไขเดียวที่จะหักล้างข้อนี้: ต้องมีพฤติกรรมที่ **Froude เท่ากันแต่วิธีเคลื่อนไหวต่างกัน** แล้วแสดงว่า latent ถ่ายทอดความต่างนั้นได้ ส่วน Froude ถ่ายไม่ได้ — **ตอนนี้ไม่มีข้อมูลแบบนั้น** คลิปทั้ง 48 แยกกลุ่มด้วย Froude พอดี
