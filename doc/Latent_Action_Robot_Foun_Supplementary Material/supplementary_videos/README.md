We indlude the video of cross embodiment action transfer in the `Action Transfer` folder, videos of the action conditioned imagined rollout in the `Imagined Rollout` folder, and the video of the planning rollout in the `Planning Rollout` folder.

For all results, we select representative videos to show the performance of the model. 
The folder structure is as follows:

```
supplementary_videos/
├── Action Transfer/
│   ├── agibot2droid/                # Transfer actions from Agibot to Droid
│   │   ├── 1/                       # Example subfolder
│   │   │   ├── agibot_refer.mp4            # Reference video of Agibot
│   │   │   ├── agibot2droid_EAC.mp4        # Transfer using action embedding from EAC-WM
│   │   │   ├── agibot2droid_LAC-MD.mp4     # Transfer using LAC-WM trained without MD
│   │   │   └── agibot2droid_LAC.mp4        # Transfer using LAC-WM trained with MD
│   │   ├── ...                       # Additional examples
│   ├── agibot2egodex/              # Transfer actions from Agibot to Egodex
│   ├── droid2agibot/               # Transfer actions from Droid to Agibot
│   ├── droid2egodex/               # Transfer actions from Droid to Egodex
│   └── egodex2agibot/              # Transfer actions from Egodex to Agibot
├── Imagined Rollout/
│   ├── EAC-WM/                     # Imagined rollouts using EAC-WM
│   ├── EAC-WM-S/                   # Imagined rollouts using EAC-WM-S
│   └── LAC-WM/                     # Imagined rollouts using LAC-WM
├── Planning Rollout/
│   ├── Training Samples/           # Rollouts generated by selecting actions from training data
│   └── VLA Samples/                # Rollouts generated by selecting actions from VLA samples

```
