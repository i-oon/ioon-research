# data — what each set is

**Naming.** `<behaviours>_<body>_<variant>`, the same rule as `wm/runs/`.

| field | values |
|---|---|
| behaviours | `beh12` -- the twelve matched conditions, speed / turn / sideways; `fwd` -- forward walking only |
| body | `c10f10t10`, `c08f09t09` for the two insect bodies by their segment ratios; `b1`; `hex8body`, `m3d`, `bracket` for multi-body Stage 1 sets |
| variant | `flat` -- one clip per file with labels; `50hz` -- the rate it was rendered at, when that is the thing about it |

**Bodies are named, never called "hexapod".** Two insect bodies with the same generic name cost a
week: the pretraining body and the held-out body turned opposite ways and every table said
"hexapod" (F108).

## The live sets

| | clips | what it is |
|---|---|---|
| `beh12_c10f10t10_flat` | 48 | the body the world model is pretrained on |
| `beh12_c08f09t09_flat` | 48 | a held-out body of the same embodiment |
| `beh12_b1_flat` | 48 | the quadruped -- the only executable candidates |

**All three turn the same way**, anticlockwise on screen, since 2026-08-29. They did not before, and
nothing that predates that can be compared across them (F106, F108). `beh12_b1_flat/README.md`
lists the four defects corrected on the quadruped side.

## Stage 1 sets, forward walking only

`fwd_hex8body`, `fwd_hex7speed`, `fwd_m3d`, `fwd_bracket`, `fwd_cov_wide`, `fwd_cov_narrow`,
`fwd_decoupled` -- the multi-body insect sets Stage 1 was measured on, and `fwd_b1_50hz`, the
quadruped set the `s2_*` runs used.

**The `fwd` prefix is the point.** Everything known about the shared body target was measured on
these, so it was measured on **one behaviour**. `fwd_b1_50hz` also names its own defect: it was
rendered at 50 Hz against the insect's 20, which made every cross-embodiment number computed with it
span mismatched durations (F65).

Several are symlink farms into `fwd_hex8body` and `fwd_decoupled` -- cheap views, not copies.

**No `_archive/` exists on disk any more** (this section used to describe one, ~700 MB of speed
and ramp sweeps, 4-leg body sets, B1 trajectory dumps, and raw pre-flatten directories). Whether it
was deleted deliberately or the reference here just went stale was not re-derivable from what is on
disk now (2026-09-23) -- if you know which, update this note.

## Egocentric sets (`data/egocentric/`, `_ego_flat` suffix, post-2026-09-01)

The `_ego_flat` suffix marks the head-mounted-camera sets; see `data/README_LAYOUT.md` for why that
split matters. Base sets (real files live here, everything else below is symlinks into these):

| | clips | what it is |
|---|---|---|
| `beh12_c10f10t10_ego_flat` | 48 | the 12-condition pretraining set, egocentric camera |
| `beh12_c10f10t10_more_ego_flat` | 240 | same 12 conditions, 20 clips each instead of 4 -- used for held-out-by-clip splits and separability checks that need more than 4 clips/condition |
| `beh12_c08f09t09_ego_flat` | 48 | the held-out insect body, same 12 conditions |
| `beh12_b1_ego_flat` | 48 | the quadruped, same 12 conditions |
| `beh12_b1_more_ego_flat` | 240 | quadruped equivalent of `beh12_c10f10t10_more_ego_flat` |
| `beh24_c10f10t10_ego_flat` | 96 | 24-condition set: the same 12 plus 12 new ones (backward speed, opposite-direction turn) -- see F234 for the beh12-vs-beh24 capacity trade-off |
| `beh24_b1_ego_flat` | 96 | quadruped equivalent of `beh24_c10f10t10_ego_flat` |
| `b1_babble_ego_flat` | 36 | quadruped motor-babble clips, first pass |
| `b1_babble_v2_ego_flat` | 36 | quadruped motor-babble, redone |
| `b1_babble_coppelia_spring_ego_flat` | 40 | quadruped motor-babble, spring-loaded joints |

**`_cleantrain`/`_cleanval`/`_cleanheldout` siblings** (e.g. `beh12_c10f10t10_ego_flat_cleantrain`)
are symlink-only views into the matching base set above, generated by `scripts/dataset/
make_clean_split.py` (beh12) or `make_clean_split_beh24.py` (beh24): stratified, disjoint,
2 clips held out per condition (1 val, 1 test). These are what `scripts/run/clean_retrain.sh` and
every diagnostic script actually train/evaluate on -- the base sets above are rarely read directly.

**`beh12_b1_ego_flat_subset{3,6,12,24}`** are symlink-only fixed-size subsets of
`beh12_b1_ego_flat`, used by fine-tune/adaptation experiments that sweep how many quadruped clips
are needed.

**A duplicate, unused copy of the clean-split symlinks used to live nested inside each base set**
(e.g. `beh12_c10f10t10_ego_flat/beh12_c10f10t10_ego_flat_cleantrain/`, alongside the real
top-level sibling). These were never git-tracked, referenced by nothing, and were removed on
2026-09-24 along with an unreferenced, untracked `fine_tune/` dir of stray subset symlinks. If a
nested `<set>/<set>_clean*` directory reappears, it is very likely another orphan of the same kind,
not a rebuild worth trusting -- check what actually reads it before relying on it.
