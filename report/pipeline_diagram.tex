% Phase 2 -- Online behaviour-matching adaptation (the z-space RL loop).
%
% Idea: don't supervise the decoder on ground-truth commands. Instead, feed the demo's
% target behaviour z_target, execute on the new body, RE-ENCODE the body's actual
% transition with ITM to get z_achieved, and drive the decoder so z_achieved -> z_target.
%   * supervision is in z-space, which is morphology-invariant -> no cross-body confound
%   * no ground-truth a_t needed
%   * BUT the a_t -> e_{t+1} step is real physics (not differentiable), so the decoder
%     is updated by RL (reward = -||z_achieved - z_target||^2), not by backprop.
%   * FTM is NOT used in this loop.
%
% Colour legend:
%   gray = frozen encoder   green = reused from Phase 1   red = new/adapted in Phase 2
%   orange = latent action z   blue = data   amber = loss   white/dashed = physical body
%   red dashed arrow = training signal (here: RL update, not a true gradient)
%
% pdflatex + TikZ -> single cropped page.
